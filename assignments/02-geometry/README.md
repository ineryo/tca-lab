# Lista 02 — Geometria Computacional

Esta atividade será resolvida incrementalmente pelo aluno. O enunciado está em [lista_02-gc.pdf](lista_02-gc.pdf), e o notebook de trabalho inicial é [solucao.ipynb](solucao.ipynb).

As primitivas e algoritmos reutilizáveis serão desenvolvidos no kernel C++ e acessados pelo namespace `tca.geometry`. Não haverá uma implementação Python paralela desses algoritmos.

As visualizações da resolução usarão Plotly diretamente no notebook. Probing, animações e infraestrutura reutilizável de visualização só serão introduzidos se uma necessidade algorítmica concreta os justificar.
